01 — ЧТО ВНУТРИ

Что делает установщик

Скрипт install-selfsteal.sh ставит всё сам: Docker, контейнер, сертификат и CLI-меню. Дальше сервисом управляют через него, а не руками по файлам.

EN / RU

Два языка интерфейса

При старте установщик спрашивает язык — 1) English или 2) Русский. Весь дальнейший интерфейс и меню работают на выбранном.

DOCKER COMPOSE

Полная контейнеризация

Автоматическая установка Docker и развёртывание контейнера через Docker Compose, с реальным выводом всех команд в терминал.

CADDY ↔ NGINX

Два веб-сервера на выбор

Caddy (caddy:2-alpine, каталог /opt/ss-caddy) или Nginx (nginx:stable-alpine, каталог /opt/nginx). Переключение — пунктом меню, без переустановки.

RANDOM % 6

Случайная заглушка

При установке одна из 6 встроенных HTML-страниц выбирается случайно. Сменить шаблон можно в любой момент из меню.

LET'S ENCRYPT

SSL без ручной рутины

Сертификат Let's Encrypt (ECC P-256), автообновление по cron и перевыпуск при смене домена. В меню виден остаток дней.

МЕНЮ 0–14

Управление одной командой

Глобальный symlink /usr/local/bin/selfssteal: статус, старт/стоп, логи, смена домена и шаблона, полное удаление.

Вопрос 1 из 5 · Домен

Какой домен использовать для SelfSteal и SSL?

На этот домен будет выпущен сертификат Let's Encrypt, и он будет прописан в serverNames (SNI).

Вопрос 2 из 5 · Веб-сервер

Какой веб-сервер развернуть в Docker?

Выбери контейнер для отдачи сайта-заглушки и приёма трафика Reality.

Вопрос 3 из 5 · Транспорт

Какой транспорт использовать для VLESS Reality?

XHTTP (SplitHTTP) маскирует передачу чанков по пути, а TCP использует классический поток Vision.

Вопрос 4 из 5 · XHTTP Path

Какой путь (XHTTP Path) настроить?

Укажи URL-путь для проксирования XHTTP-чанков (например, /media/v3/chunk/).

Вопрос 5 из 5 · Target Port

Какой локальный Target порт использовать?

Локальный адрес и порт, который слушает контейнер SelfSteal (и куда Xray направляет Reality dest).

├── docker-compose.yml        # манифест: selfsteal-caddy, caddy:2-alpine, host network

07 — КОНФИГ XRAY

streamSettings для инбаунда

SelfSteal отдаёт сайт-прикрытие на 127.0.0.1:9443 — этот адрес указывается как target (dest) в Reality. Значения домена, ключей и ShortId подставь свои.

  • Target (Dest)127.0.0.1:9443
  • ServerNames (SNI)poland.example.xyz
  • XHTTP Path/media/v3/chunk/
  • Private KeyYOUR_X25519_PRIVATE_KEY
  • Public KeyYOUR_X25519_PUBLIC_KEY
  • ShortIda1b2c3d4e5f60718

Полный URL пути XHTTP в примере из README: poland.example.xyz/media/v3/chunk/. Режим XHTTP — auto, поле show в realitySettings выключено.

streamSettings.json 
{
  "streamSettings": {
    "network": "xhttp",
    "security": "reality",
    "realitySettings": {
      "show": false,
      "serverNames": ["poland.example.xyz"],
      "privateKey": "YOUR_X25519_PRIVATE_KEY",
      "publicKey": "YOUR_X25519_PUBLIC_KEY",
      "shortIds": ["a1b2c3d4e5f60718"]
    },
    "xhttpSettings": {
      "path": "/media/v3/chunk/",
      "host": "poland.example.xyz",
      "mode": "auto"
    }
  }
}
